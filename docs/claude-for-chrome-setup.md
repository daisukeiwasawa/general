# Claude for Chrome への依頼文（Apps Script のデプロイ）

イトーキ配送の日次売上計上を動かすには、スプレッドシート側に Apps Script のウェブアプリを
1回だけ置く必要がある。GitHub Actions は Google のセルを直接編集できないため、
シート側に「書き込みを受け付ける窓口」を作る形にしている。

この作業は Google アカウントにログインしたブラウザが必要なので、Claude for Chrome に頼む。
以下をそのまま Claude for Chrome に貼り付ける。

---

## 貼り付ける依頼文

```
Google スプレッドシートに Apps Script のウェブアプリを設置してほしい。
以下の手順どおりに進めて、最後に指定した情報を報告して。

【手順1】コードをコピーする
1. https://github.com/daisukeiwasawa/general/blob/claude/itoki-daily-sales-process-cvoj8e/apps_script/Code.gs を開く
2. ファイル右上の「Raw」ボタンの隣にある「Copy raw file」ボタンを押してコードを丸ごとコピーする
   （ボタンが見つからなければ「Raw」を開いて全選択→コピーでもよい）

【手順2】Apps Script にコードを貼る
1. https://docs.google.com/spreadsheets/d/10MbFX-RhVv_FDfCCugdZhPBwLj7eLHdtK-SHaIgQFTs/edit を開く
2. メニューの「拡張機能」→「Apps Script」を選ぶ（新しいタブが開く）
3. エディタに最初から入っている `function myFunction() {}` などを全部消して、
   手順1でコピーしたコードを貼り付ける
4. プロジェクト名を「イトーキ売上連携」に変更する（画面上部の「無題のプロジェクト」をクリック）
5. 保存する（Ctrl+S またはフロッピーディスクのアイコン）

【手順3】スクリプト プロパティを2つ設定する
1. 左サイドバーの歯車アイコン「プロジェクトの設定」を開く
2. 一番下の「スクリプト プロパティ」→「スクリプト プロパティを追加」
3. 次の2つを追加して「スクリプト プロパティを保存」を押す

   プロパティ: TOKEN
   値: ランダムな英数字40文字をあなたが生成して設定する。
       設定した値は最後の報告に必ず含めること（GitHub 側に同じ値を登録するため）。

   プロパティ: SHIFT_FILE_ID
   値: 1pB-YyAPFQEJ4zMoeLZ7ojihc8NqeL4NK

【手順4】Drive API を有効にする
1. 左サイドバーの「サービス」の右にある「＋」を押す
2. 一覧から「Drive API」を選ぶ
3. バージョンが「v3」、IDが「Drive」になっていることを確認して「追加」を押す
   ※シフト表が .xlsx 形式のため、読むときに一時変換する。これが無いと動かない。

【手順5】テスト実行して設定を確かめる
1. エディタ上部の関数プルダウンから「testFindCell」を選び「実行」を押す
2. 「承認が必要です」と出たら「権限を確認」→ Google アカウントを選ぶ
3. 「このアプリは Google で確認されていません」と出たら、
   「詳細」→「イトーキ売上連携（安全ではないページ）に移動」→「許可」と進む
4. 画面下部の「実行ログ」に、書き込み先のセル（例: 2026.09 の AJ12）が出れば成功
5. 続けて関数プルダウンから「testShiftLookup」を選んで「実行」
   実行ログに drivers として担当者の名前が出れば成功
   ※どちらかでエラーが出たら、そこで止めてエラー文をそのまま報告して

【手順6】ウェブアプリとしてデプロイする
1. 画面右上の「デプロイ」→「新しいデプロイ」
2. 左上の歯車「種類の選択」→「ウェブアプリ」を選ぶ
3. 次のように設定する
   - 説明: イトーキ売上連携
   - 次のユーザーとして実行: 自分（メールアドレスが表示されているもの）
   - アクセスできるユーザー: 全員
     ※「全員」以外だとGitHub Actionsから呼べない。合言葉(TOKEN)で保護している。
4. 「デプロイ」を押す。承認画面が出たら手順5と同じ要領で許可する
5. 表示される「ウェブアプリ」の URL（https://script.google.com/macros/s/... /exec で終わるもの）をコピーする

【最後に報告してほしいこと】
1. 手順3で設定した TOKEN の値
2. 手順6でコピーしたウェブアプリの URL
3. 手順5の testFindCell / testShiftLookup の実行ログの内容
4. 途中でエラーや想定と違う画面が出た場合はその内容

途中で判断に迷う画面が出たら、勝手に進めずに聞いてほしい。
```

---

## 報告が返ってきたあとにやること

GitHub の **Settings → Secrets and variables → Actions** で次の2つを登録する。

| Secret 名 | 入れる値 |
|---|---|
| `SHEET_WEBAPP_TOKEN` | 報告された TOKEN の値 |
| `SHEET_WEBAPP_URL` | 報告されたウェブアプリの URL |

ウェブアプリの URL と TOKEN は**2つ揃うとシートに書き込める鍵**になる。
チャットやメールに残さず、GitHub Secrets に入れたら消しておくこと。

## コードを直したときの再デプロイ

Apps Script のコードを更新したら、「デプロイを管理」→ 鉛筆アイコン →
バージョンを「新バージョン」にして「デプロイ」。URL は変わらない。
